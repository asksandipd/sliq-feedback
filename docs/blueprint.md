# **App Name**: Feedback Flow

## Core Features:

- Breadcrumb Navigation: Implement a breadcrumb navigation for clear page hierarchy.
- Tabbed Pages: Implement a tabbed interface for organizing content sections.
- Feedback Slider: Add a feedback slider accessible via a toggle button, including snapshot capture, highlighting, and information capture (account/system info).

## Style Guidelines:

- Primary color: Material UI's primary blue for a professional look.
- Secondary color: Light gray for backgrounds and subtle accents.
- Accent: Teal (#008080) for the feedback toggle and highlight elements.
- Responsive layout using Tailwind CSS grid and flexbox for optimal viewing on different devices.
- Material Design icons for a consistent and recognizable user experience.
- Subtle slide-in animation for the feedback slider.
